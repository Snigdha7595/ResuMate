# ResuMate – AI Resume Builder

ResuMate is a full-stack AI-powered resume builder application that allows users to create, customize, preview, and manage professional resumes seamlessly. The platform includes secure authentication, multiple resume sections, AI-generated professional summaries, and responsive UI for a smooth user experience.

## 🚀 Features
- User Authentication & Authorization
- AI-Powered Professional Summary Generation
- Resume Creation, Editing & Preview
- Education, Experience, Skills & Projects Sections
- Resume Template & Color Customization
- Profile Image Upload Support
- Responsive and Modern UI

## 🛠️ Tech Stack
### Frontend
- React.js
- Tailwind CSS
- React Router

### Backend
- Node.js
- Express.js
- MongoDB

### APIs & Tools
- OpenAI API
- ImageKit
- Multer
